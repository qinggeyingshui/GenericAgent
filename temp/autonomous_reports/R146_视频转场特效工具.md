# R146: 视频转场特效工具

## 任务目标
为视频制作提供专业转场特效，支持5种转场效果，提升视频制作质量。

## 产出文件
- **video_effects.py** (7157 bytes)
  - 位置: temp/tools/video_effects.py
  - 依赖: moviepy

## 核心功能

### 1. 淡入淡出 (FADE)
- 透明度渐变转场
- 适用场景：平滑过渡、情感转换

### 2. 滑动 (SLIDE)
- 支持4个方向：LEFT/RIGHT/UP/DOWN
- 第二个视频从指定方向滑入
- 适用场景：场景切换、空间转换

### 3. 缩放 (ZOOM)
- 第二个视频从0.1倍放大到1倍
- 同时淡入效果
- 适用场景：聚焦、强调

### 4. 旋转 (ROTATE)
- 第二个视频旋转进入（360度→0度）
- 同时缩放效果（0.3倍→1倍）
- 适用场景：动感转场、创意效果

### 5. 擦除 (WIPE)
- 支持4个方向：LEFT/RIGHT/UP/DOWN
- 像擦除一样覆盖前一个视频
- 适用场景：揭示、翻页效果

## API接口

### add_transition()
```python
add_transition(clip1_path, clip2_path, output_path, 
               transition_type="fade", duration=1.0, direction="left")
```
- **clip1_path**: 第一个视频路径
- **clip2_path**: 第二个视频路径
- **output_path**: 输出视频路径
- **transition_type**: 转场类型（FADE/SLIDE/ZOOM/ROTATE/WIPE）
- **duration**: 转场时长（秒），建议0.5-2.0秒
- **direction**: 方向（仅SLIDE和WIPE需要）

### batch_add_transitions()
```python
batch_add_transitions(video_paths, output_path, 
                     transition_type="fade", duration=1.0)
```
批量为多个视频添加转场效果。

## 使用示例

### 示例1：淡入淡出转场
```python
from tools.video_effects import add_transition, FADE

add_transition("intro.mp4", "main.mp4", "output.mp4", 
               transition_type=FADE, duration=1.0)
```

### 示例2：滑动转场
```python
from tools.video_effects import add_transition, SLIDE, LEFT

add_transition("scene1.mp4", "scene2.mp4", "output.mp4",
               transition_type=SLIDE, duration=1.5, direction=LEFT)
```

### 示例3：批量转场
```python
from tools.video_effects import batch_add_transitions, FADE

videos = ["clip1.mp4", "clip2.mp4", "clip3.mp4", "clip4.mp4"]
batch_add_transitions(videos, "final.mp4", transition_type=FADE, duration=1.0)
```

## 技术实现

### 核心技术
- **moviepy.CompositeVideoClip**: 视频合成
- **时间函数**: lambda函数定义时间相关的变换
- **遮罩技术**: numpy数组实现擦除效果

### 转场原理
1. **淡入淡出**: 使用fadeout/fadein效果
2. **滑动**: 动态修改position属性
3. **缩放**: 动态修改resize属性
4. **旋转**: 结合旋转和缩放
5. **擦除**: 使用numpy遮罩逐步显示
