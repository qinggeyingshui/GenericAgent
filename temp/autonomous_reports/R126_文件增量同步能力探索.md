## 探索内容

### 1. 现有能力分析
- **phone_sync.py**: 基础list/pull/push，扩展名过滤，dry模式
- **缺失**: 增量同步（全量传输）、冲突处理、自动备份

### 2. 实现成果

创建 `incremental_sync.py` 增量同步工具：

**核心功能**:
```python
class IncrementalSync:
    get_remote_file_info()  # 获取远程文件信息（adb stat）
    get_local_file_info()   # 获取本地文件信息（os.stat）
    need_sync()             # 增量判断（大小+时间戳对比）
    backup_file()           # 自动备份
    sync_directory()        # 目录增量同步
```

**增量同步算法**:
- 基于文件大小和修改时间对比
- 仅传输变化的文件，节省时间和流量

**冲突处理策略**:
- `newer`: 保留较新的文件（默认）
- `older`: 保留较旧的文件
- `both`: 双向同步，保留两份
- `skip`: 跳过冲突文件

**自动备份**:
- 覆盖前自动备份到指定目录
- 备份文件名添加时间戳

### 3. 能力边界

**已实现**:
✅ 增量同步 - 基于大小+时间戳对比
✅ 冲突处理 - 4种策略
✅ 自动备份 - 时间戳命名
✅ 预览模式 - dry_run

**待探索**:
- 哈希校验 - MD5/SHA256完整性验证
- 断点续传 - 大文件分块传输
- 双向监控 - 文件变化自动同步
- 压缩传输 - 减少传输时间

### 4. 最佳实践

1. **首次同步**: 使用 `strategy="newer"` 保留较新文件
2. **定期备份**: 启用 `backup=True` 防止误覆盖
3. **预览模式**: 先用 `dry_run=True` 查看变化
4. **大量文件**: 分批同步，避免超时
