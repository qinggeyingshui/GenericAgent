## 探索内容

### 1. 现有能力分析
- **TMWebDriver**: CDP桥扩展，支持跨tab操作、batch命令、tabs查询
- **现有功能**: web_scan/web_execute_js 直接调用，支持后台标签操作
- **现状**: 缺少多标签协同的最佳实践和示例代码

### 2. 实现成果

创建 `multi_tab_helper.py` 多标签协同助手：

**核心功能**:
```python
class MultiTabHelper:
    list_tabs() -> 获取所有标签页
    share_data_between_tabs() -> 多标签数据传递
    sync_operation_across_tabs() -> 跨标签同步操作
    capture_captcha() -> 验证码截图
```

**关键技术**:
1. **多标签数据传递**:
   - localStorage: 同域名自动共享
   - sessionStorage: 仅当前会话
   - BroadcastChannel: 实时通信

2. **跨标签同步操作**:
   - CDP batch 命令: 一次请求多个操作
   - 后台标签支持: 无需切换到前台

3. **验证码处理**:
   - CDP截图: Page.captureScreenshot
   - Canvas导出: canvas.toDataURL()
   - 区域截图: 先获取位置，再CDP指定区域

### 3. 使用示例

**获取标签页列表**:
```python
web_execute_js(script='{"cmd": "tabs"}')
# 返回: {ok: true, tabs: [{id, url, title, active}, ...]}
```

**多标签数据共享**:
```javascript
// 标签页A写入
localStorage.setItem('data', 'value')

// 标签页B读取
localStorage.getItem('data')
```

**跨标签同步刷新**:
```python
batch_cmd = {
    "cmd": "batch",
    "commands": [
        {"cmd": "cdp", "tabId": 123, "method": "Page.reload", "params": {}},
        {"cmd": "cdp", "tabId": 456, "method": "Page.reload", "params": {}}
    ]
}
web_execute_js(script=json.dumps(batch_cmd))
```

**验证码截图**:
```python
# CDP全页截图
cdp_cmd = {"cmd": "cdp", "method": "Page.captureScreenshot", "params": {"format": "png"}}
result = web_execute_js(script=json.dumps(cdp_cmd))
# result["data"] 包含 base64 图片
```

### 4. 能力边界

**已实现**:
- ✅ 跨标签操作 (CDP batch，支持后台标签)
- ✅ 数据共享 (localStorage/BroadcastChannel，同域名)
- ✅ 验证码截图 (CDP/Canvas)
- ✅ 跨域iframe (Page.getFrameTree + createIsolatedWorld)

**待探索**:
- ⚠️ 验证码识别: 需要外部OCR服务 (tesseract, 百度OCR等)
- ⚠️ 跨域数据传递: 需要服务器中转或扩展API
- ⚠️ 自动化验证码处理: 需要集成OCR和自动填充

### 5. 最佳实践

1. **多标签操作**: 优先使用 CDP batch 命令，减少通信开销
2. **数据共享**: 同域名用 localStorage，跨域需服务器中转
3. **验证码处理**: CDP截图 + 外部OCR服务
4. **后台标签**: 直接指定 tabId，无需切换到前台
