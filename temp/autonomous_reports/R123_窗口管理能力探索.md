## 探索内容

### 1. 现有能力分析
- **ljqCtrl**: 鼠标/键盘模拟、找图、DPI处理，但无窗口布局功能
- **win32gui**: Windows原生API，功能强大
- **现状**: 项目中无专门的窗口布局管理工具

### 2. 实现成果

创建 `window_layout_manager.py` 窗口布局管理器：

**核心功能**:
```python
class WindowLayoutManager:
    find_window(title) -> hwnd
    get_window_info(title) -> Dict  # 位置/大小/状态
    
    # 基础操作
    move_window(title, x, y)
    resize_window(title, width, height)
    
    # 状态控制
    maximize_window(title)
    minimize_window(title)
    restore_window(title)
    
    # 高级布局
    tile_windows(titles, layout)  # grid/horizontal/vertical
    cascade_windows(titles, offset)
```

**布局模式**:
- **Grid**: 网格平铺，自动计算行列
- **Horizontal**: 水平平铺
- **Vertical**: 垂直平铺
- **Cascade**: 层叠窗口，带偏移量

### 3. 技术要点

**窗口查找**:
- 使用 `EnumWindows` 枚举所有窗口
- 支持标题模糊匹配
- 过滤不可见窗口

**窗口操作**:
- `SetWindowPos()` - 设置位置和大小
- `ShowWindow()` - 控制窗口状态
- `GetWindowPlacement()` - 获取窗口状态

**坐标系统**:
- win32gui 返回逻辑坐标
- 需要配合 ljqCtrl.dpi_scale 转换物理坐标
- 操作前建议先 activate 窗口

### 4. 能力边界

**已实现**:
✅ 窗口查找和信息获取
✅ 移动和调整大小
✅ 最大化/最小化/恢复

**未实现** (待探索):

❌ 窗口分组管理
❌ 布局预设保存/恢复
❌ 窗口吸附和对齐

### 5. 最佳实践

1. **窗口查找**: 使用部分标题匹配，提高兼容性
2. **状态检查**: 操作前检查窗口是否存在
3. **错误处理**: 所有操作都有异常捕获
4. **布局计算**: 平铺时考虑屏幕大小和窗口数量

### 6. 使用示例

```python
from tools.window_layout_manager import WindowLayoutManager

manager = WindowLayoutManager()

# 移动窗口
manager.move_window('记事本', 100, 100)

# 调整大小
manager.resize_window('记事本', 800, 600)

# 平铺多个窗口
manager.tile_windows(['窗口1', '窗口2', '窗口3'], 'grid')

# 层叠窗口
manager.cascade_windows(['窗口1', '窗口2'])
```
