### 2. 核心模块

#### AccountManager - 账号管理器
```python
class AccountManager:
    def add_account(platform, username, **kwargs) -> str
    def remove_account(account_id) -> bool
    def list_accounts(platform=None) -> List[Dict]
```

```python
class PlatformSync:
```

**功能**：

## 使用示例

### 基础使用
```python
import sys
sys.path.append('./tools')
import account_manager

# 添加账号
mgr = account_manager.AccountManager()
acc_id = mgr.add_account("wechat", "user1", nickname="昵称")

# 同步数据
sync = account_manager.PlatformSync()
sync.sync_posts(acc_id, [{"post_id": "p1", "title": "文章"}])
sync.sync_stats(acc_id, {"views": 100, "likes": 10})

# 监控状态
monitor = account_manager.StatusMonitor(mgr)
status = monitor.check_login_status(acc_id)
summary = monitor.get_account_summary(acc_id)
```

### 快速使用
```python
# 快速添加账号
acc_id = account_manager.quick_add_account("zhihu", "user2")

# 快速同步发布
account_manager.quick_sync_post(acc_id, "p1", "文章标题")
```
