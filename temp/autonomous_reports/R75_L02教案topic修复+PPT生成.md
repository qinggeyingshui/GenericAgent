Windows将路径名中的` / `解析为目录分隔符，导致：
```
FileNotFoundError: [WinError 3] 系统找不到指定的路径。:
'...slides\图神经网络与大语言模型_图神经网络基础（图结构定义 \ 消息传递框架 '
```

## 修复方案

将topic中的` / `替换为中文顿号`、`：
- 修复前：`图神经网络基础（图结构定义 / 消息传递框架 / GCN推导）`
- 修复后：`图神经网络基础（图结构定义、消息传递框架、GCN推导）`

## 经验沉淀

lesson2ppt.py 生成的PPTX文件名直接使用topic字段，topic中含Windows路径非法字符（`/`, `\`, `:`, `*`, `?`, `"`, `<`, `>`, `|`）会导致makedirs失败。
建议在lesson2ppt.py的output_path生成处增加路径清理函数，自动替换非法字符。
