## 实现方案
### 1. 多源数据导入
**BibTeX导入** (import_from_bibtex):
- 解析.bib文件
- 提取title/author/year/venue
- 批量导入到知识库

**PDF元数据导入** (import_from_pdf_metadata):
- 从文件名提取信息
- 支持标准命名格式
- 单文件快速导入

**Markdown导入** (import_from_markdown):
- 解析YAML-like格式
- 兼容现有PAPERS.md格式
- 批量导入

### 2. 自动去重算法
**去重检查** (_is_duplicate):
- ID完全匹配检查
- 标题完全匹配检查
- 相似度阈值检查(>0.8)

**相似度计算** (calc_similarity):
- Jaccard相似度算法
- 基于词集合计算
- 返回0-1之间的分数

### 3. 同步状态追踪
**多源同步** (sync_from_sources):
- 支持多个数据源批量同步
- 统计成功/失败/重复数量
- 计算同步成功率

**状态查询** (get_sync_status):
- 总论文数统计
- 数据源分布统计
- 实时状态查询

## 核心代码
```python
# 多源同步示例
sources = [
    {"type": "bibtex", "path": "papers.bib"},
    {"type": "markdown", "path": "papers.md"},
    {"type": "pdf", "path": "paper.pdf"}
]
result = sync_from_sources(sources)
print(f"成功率: {result['success_rate']:.1f}%")

# 去重检查
paper = {"id": "arxiv123", "title": "Test Paper"}
if not _is_duplicate(paper):
    add_paper(paper)

# 相似度计算
sim = calc_similarity("Graph Neural Networks", "Neural Networks")
print(f"相似度: {sim:.2f}")
```
