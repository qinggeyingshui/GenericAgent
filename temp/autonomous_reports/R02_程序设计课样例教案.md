## 二、教学目标

### 1. 知识目标

- 理解程序的三种基本结构：顺序、分支、循环，重点掌握**分支结构的作用**。  
- 掌握 C 语言中 `if` 语句的三种常见形式：  
  1. 单分支：`if (condition) statement;`  
  2. 双分支：`if (condition) {...} else {...}`  
  3. 多分支：`if (c1) ... else if (c2) ... else ...`  
- 理解关系运算符和逻辑运算符的含义与用法（`>`, `<`, `>=`, `<=`, `==`, `!=`, `&&`, `||`, `!`）。  
- 了解嵌套 `if` 的基本结构和“悬挂 else”问题。

### 2. 能力目标

- 能将自然语言中的条件描述转化为 C 语言条件表达式。  
- 能使用 `if` 语句解决简单的逻辑分支问题（如：奇偶判断、及格与否、等级划分）。  
- 能阅读含分支结构的 C 程序，分析不同输入下程序的执行路径和输出结果。  

### 3. 素养与习惯目标

- 形成“先逻辑、后编码”的习惯：先列出所有可能情况，再写条件和代码。  
- 养成良好的代码风格：缩进规范、花括号使用一致、命名清晰。  
- 通过生活化示例认识到程序设计与现实逻辑的紧密联系，增强学习动机。

---

## 三、学情分析

- 多数学生刚接触编程，能写简单的输入-计算-输出顺序程序。  
- 对“布尔逻辑”“条件表达式”较陌生，部分学生在数学逻辑上有一定困难。  
- 常见问题：  
  - 将 `=` 与 `==` 混用，把赋值写成比较。  
  - 条件表达式书写不完整或不合法（如：`if (x > 1 && < 10)`）。  
  - 缺少花括号或缩进混乱导致逻辑与预期不符。  
  - 多分支条件覆盖不全，存在遗漏情况。

---

## 四、教学重难点

- 教学重点：  
  1. `if` 单分支、双分支、多分支的语法形式与执行流程。  
  2. 条件表达式的正确书写与关系/逻辑运算符的组合使用。

- 教学难点：  
  1. 自然语言条件 → C 语言条件表达式的正确映射。  
  2. 嵌套 `if` 与“悬挂 else”问题，以及代码风格对逻辑理解的影响。  
  3. 对分支逻辑的“覆盖性”思考和测试。

## 六、教学过程

> 下表按“环节—教师活动—学生活动—设计意图”组织，可视为可复用模板。

### 环节一：情境导入（约 10 分钟）

- **教师活动**  
  1. 提出情境问题：  
     - “如果成绩 ≥ 60 就输出‘及格’，否则输出‘不及格’，你能用现在学过的顺序结构写出这样的程序吗？”  
  2. 鼓励学生尝试听起来“顺序化”的方案，让学生意识到难以直接表达“二选一”的逻辑。  
  3. 板书或展示若干生活中的“如果…就…”场景，引出“分支结构”的概念。  

- **学生活动**  
  - 思考顺序结构的局限性，自发提出需要“有条件地执行不同代码”的想法。  
  - 分享生活中的条件判断例子（如下雨带伞，成绩分等级等）。

- **设计意图**  
  - 创造“认知冲突”，让学生对分支结构产生真实需求，而不是被动接受新语法。

---

### 环节二：单分支 if 语句与关系运算（约 20 分钟）

- **教师活动**  
  1. 板书 `if` 单分支基本形式，并说明含义：  

     ```c
     if (condition)
         statement;
     ```

  2. 介绍常见关系运算符，举例说明它们的真假值判断。  
  3. 示范“判断偶数”程序：

     ```c
     #include <stdio.h>

     int main() {
         int x;
         printf("请输入一个整数: ");
         scanf("%d", &x);

         if (x % 2 == 0)
             printf("x 是偶数\n");

         printf("程序结束\n");
         return 0;
     }
     ```

  4. 在 IDE 中实际运行程序，让学生观察当条件为真与不真时执行路径的差异。

- **学生活动**  
  - 根据自然语言“如果 x 能被 2 整除，就输出‘x 是偶数’”写出条件 `x % 2 == 0`。  
  - 修改程序尝试其它条件（如“能被 3 整除”“大于 0”等），观察程序行为。  

- **设计意图**  
  - 通过简洁例子建立“条件为真才执行”的直观印象，为后续复杂分支打基础。

---

### 环节三：if...else 双分支结构（约 25 分钟）

- **教师活动**  
  1. 将“偶数判断”扩展为“偶数/奇数分类”：

     ```c
     if (x % 2 == 0)
         printf("x 是偶数\n");
     else
         printf("x 是奇数\n");
     ```

  2. 进一步引入成绩是否及格的示例：

     ```c
     if (score >= 60)
         printf("及格\n");
     else
         printf("不及格\n");
     ```

  3. 强调：  
     - `if` 与 `else` 成对出现，`else` 对应最近的 `if`。  
     - 注意花括号：当语句块包含多条语句时，必须加 `{}`。  

  4. 展示错误示例（不使用花括号）并解释逻辑错误：

     ```c
     if (score >= 60)
         printf("及格\n");
         printf("继续努力\n");  // 实际不受 if 控制
     ```

- **学生活动**  
  - 完成课堂练习：输入一个整数 n，判断其为正数还是非正数（≥0 or <0）。  
  - 在黑板/投影上由学生写出代码，全班一起检查花括号与缩进。  

- **设计意图**  
  - 引导学生理解互斥的两种结果（if/else），并提升对代码结构与缩进的敏感度。

---

### 环节四：多分支 if-else-if 结构（约 25 分钟）

- **教师活动**  
  1. 引出需求：根据成绩划分等级 A/B/C/D。  
  2. 板书规则并写出示例代码：

     ```c
     if (score >= 90)
         printf("A\n");
     else if (score >= 80)
         printf("B\n");
     else if (score >= 70)
         printf("C\n");
     else
         printf("D\n");
     ```

  3. 提问：为什么第二个条件只写 `score >= 80` 就够了？  
     - 引导学生理解：一旦前面条件满足，就不会再判断后面的条件。  
  4. 与学生一起检查不同边界值（79、80、89、90）对应的输出。  

- **学生活动**  
  - 小组讨论一个自定义的等级划分规则，并尝试用 `if-else-if` 编写程序。  
  - 每组选派一名同学展示代码，全班共评其条件是否覆盖所有情况。  

- **设计意图**  
  - 训练学生对区间划分、条件覆盖与分支顺序的整体把握。

---

### 环节五：课堂小测与总结（约 15 分钟）

- **教师活动**  
  1. 发放或展示小测题（例）：  
     - 题1：写出表达“x 在 1 到 10 之间（含 1 和 10）”的条件表达式。  
     - 题2：以下两段代码是否等价？如不等价，给出反例。  
     - 题3：阅读一段含 `if-else-if` 的代码，填写不同输入下的输出结果。  
  2. 汇总学生答题情况，针对共性错误进行讲评。  
  3. 总结本节课重点与难点，预告下一节课内容（如 `switch` 语句或循环结构）。  

- **学生活动**  
  - 独立完成小测并对照讲解修正错误。  
  - 用自己的话总结“写一个分支程序的基本步骤”。

- **设计意图**  
  - 通过及时检测和反馈，强化正确理解，纠正常见误区。

## 八、作业与拓展

### 1. 基础作业

1. 输入一个整数，判断其是否为 3 的倍数。  
2. 输入一个年份，判断是否是闰年（规则给定）。  

### 2. 提高作业

3. 输入三门课程成绩，计算平均分并输出等级：  
   - 平均分 ≥ 85：优秀  
   - 70–84：良好  
   - 60–69：及格  
   - 其他：不及格  

4. 自选一个生活场景（如地铁票价、外卖配送费、手机套餐计费等），设计一套分档规则并用 `if-else-if` 实现。

### 3. 要求

- 每道题提供至少 3 组测试数据及预期输出。  
- 提交源代码与运行截图。
