## 实现内容

### 1. RetryManager 核心模块
创建 `tools/retry_manager.py` (263行)，提供完整的失败重试管理能力。

#### 核心功能
1. **重试策略配置**
   ```python
   config = {
       "max_retries": 3,           # 最大重试次数
       "retry_delay": 60,          # 基础延迟(秒)
       "backoff_type": "exponential",  # 退避算法
       "backoff_factor": 2         # 退避因子
   }
   ```

2. **三种退避算法**
   - `fixed`: 固定延迟 (delay)
   - `linear`: 线性退避 (delay × retry_count)
   - `exponential`: 指数退避 (delay × backoff_factor^retry_count)

3. **状态持久化**
   - JSON格式存储重试状态
   - 记录: 重试次数、失败时间、下次重试时间、错误信息
   - 自动清理成功任务的状态

#### API设计
```python
from retry_manager import RetryManager

rm = RetryManager("retry_state.json")

# 检查是否应该重试
should_retry, delay = rm.should_retry(task_id, config)

# 记录失败
rm.record_failure(task_id, error_message, config)

# 记录成功
rm.record_success(task_id)

# 查询状态
status = rm.get_retry_status(task_id)
```

### 2. 集成示例
创建 `tools/retry_integration_example.py`，演示如何与现有调度系统集成。

#### 核心集成逻辑
```python
def run_task_with_retry(task_id, task_func, retry_config):
    # 1. 检查重试条件
    should_retry, delay = retry_mgr.should_retry(task_id, retry_config)
    if not should_retry:
        return False
    
    # 2. 执行任务
    try:
        task_func()
        retry_mgr.record_success(task_id)  # 成功
        return True
    except Exception as e:
        retry_mgr.record_failure(task_id, str(e), retry_config)  # 失败
        return False
```

## 使用建议

### 推荐配置
- **网络请求**: exponential退避，max_retries=3，delay=60s
- **文件操作**: linear退避，max_retries=5，delay=30s
- **轻量任务**: fixed延迟，max_retries=3，delay=10s
