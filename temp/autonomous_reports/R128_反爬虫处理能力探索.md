### 2. 方案设计

基于现有 CDP 能力，设计反爬虫工具包：

**核心模块**：
1. **UserAgentRotator** - UA 轮换器
   - 内置 20+ 常见浏览器 UA
   - 支持随机选择和顺序轮换
   - 通过 CDP `Network.setUserAgentOverride` 设置

2. **RequestDelayManager** - 请求延迟管理
   - 随机延迟（模拟人类行为）
   - 可配置延迟范围（默认 1-3 秒）

3. **RateLimiter** - 限流器
   - 滑动窗口算法
   - 可配置时间窗口和最大请求数
   - 自动等待直到可用

4. **DynamicContentWaiter** - 动态内容等待
   - 基于 CDP `DOM.querySelector` 轮询
   - 网络空闲检测（`Network.enable` + 事件监听）
   - 可配置超时和轮询间隔

5. **CookieManager** - Cookie 管理
   - 获取/设置/清除 Cookie
   - 支持 URL 过滤
   - 基于 CDP `Network.getCookies` / `Network.setCookie`

6. **AntiScrapingStrategy** - 综合策略
   - 整合上述所有模块
   - `safe_navigate()` - 安全导航（自动 UA 轮换 + 延迟）
   - `batch_scrape()` - 批量抓取（带限流）
   - `prepare_request()` - 请求前准备

### 3. 实现细节

**技术栈**：
- Python 标准库（random, time, json）
- web_execute_js 工具（CDP 命令注入）
- CDP batch 命令（减少往返次数）

**关键设计**：
```python
# CDP 命令格式
cdp_cmd = {
    "cmd": "cdp",
    "method": "Network.setUserAgentOverride",
    "params": {"userAgent": ua}
}
web_execute_js(script=json.dumps(cdp_cmd))

# Batch 命令（减少延迟）
batch_cmd = {
    "cmd": "batch",
    "commands": [
        {"cmd": "cdp", "method": "DOM.getDocument", ...},
        {"cmd": "cdp", "method": "DOM.querySelector", ...}
    ]
}
```

**坑点记录**：
1. ✗ 初次使用 `\u2713` Unicode 字符导致 GBK 编码错误
   - 解决：替换为 ASCII `[OK]` / `[X]`

2. ✗ 示例脚本调用了不存在的方法（`rotate_user_agent()`）
   - 解决：改用 `safe_navigate()` 和 `prepare_request()`
