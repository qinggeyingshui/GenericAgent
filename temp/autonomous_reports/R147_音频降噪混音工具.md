# R147: 音频降噪混音工具

## 任务目标
为音频制作提供专业增强能力，支持降噪、混音、音量均衡，提升音频质量。

## 产出文件
- **audio_enhance.py** (3839 bytes)
  - 位置: temp/tools/audio_enhance.py
  - 依赖: pydub（无需noisereduce）

## 核心功能

### 1. 降噪处理 (reduce_noise)
- 使用高通/低通滤波器去除噪音
- 人声频段：80Hz-8000Hz
- 去除低频噪音（空调、风扇）和高频噪音（电流声）

### 2. 混音处理 (mix_audio)
- 人声+背景音乐混合
- 支持独立音量调整
- 背景音乐自动循环播放（如果比人声短）
- 建议背景音乐降低10-15dB

### 3. 音量均衡 (normalize_volume)
- 自动调整到标准响度
- 支持多种标准：
  - 播客/视频配音：-20 dBFS
  - 音乐：-14 dBFS
  - 广播：-6 dBFS
- 防止削波（clipping）

### 4. 一键增强 (enhance_voice)
- 降噪+音量均衡组合
- 适合快速处理播客、视频配音

## 技术方案

### 降噪实现
- 不依赖noisereduce库（fallback方案）
- 使用pydub的high_pass_filter和low_pass_filter
- 原理：保留人声主要频段（80Hz-8000Hz），过滤噪音频段

### 混音实现
- 使用pydub的overlay功能
- 支持音量调整和时长匹配
- 自动处理背景音乐循环

### 音量均衡实现
- 计算当前响度(dBFS)
- 调整到目标响度
- 应用normalize防止削波

## 应用场景
1. **播客制作**: 降噪+音量均衡，提升人声清晰度
2. **视频配音**: 混音背景音乐，调整音量平衡
3. **音频修复**: 去除录音中的背景噪音
4. **批量处理**: 统一多个音频的响度标准

## 验收标准
- ✓ 支持降噪（高通/低通滤波器）
- ✓ 支持混音（人声+背景音乐）
- ✓ 支持音量均衡（多种标准）
- ✓ 基于pydub，无需额外依赖
- ✓ 更新audio_processing_sop第5节

## 使用示例
```python
from tools.audio_enhance import enhance_voice, mix_audio

# 快速增强人声
enhance_voice('recording.mp3', 'enhanced.mp3')

# 添加背景音乐
mix_audio('voice.mp3', 'bgm.mp3', 'final.mp3', bgm_volume=-12)
```
