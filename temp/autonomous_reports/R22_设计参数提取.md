# R22 - 逆向提取本地优秀模板设计参数体系

## 任务目标
从 `ppt_lab/` 中的两个优秀模板（夏令营答辩参考3.pptx、模板4.pptx）逆向提取完整的设计参数体系，输出可复用的 `design_tokens.json`。

## 分析方法
1. **python-pptx API 解析**：提取字体、字号、文本颜色、布局名称、形状装饰
2. **ZIP/XML 深度提取**：直接读取 PPTX 内部的 `theme*.xml` 获取完整主题色方案和字体方案
3. **装饰形状分析**：提取前5页的非文本装饰元素（色块、多边形、线条等）的位置、尺寸、填充色

## 核心发现

### 配色方案 A：学术蓝紫（夏令营答辩参考3）
| 角色 | 色值 | 说明 |
|------|------|------|
| Primary | #1D2974 | 藏蓝，主色调 |
| Secondary | #26379A | 蓝色，辅助 |
| Accent1 | #8A97E2 | 浅蓝紫 |
| Accent2 | #AA71E2 | 紫色 |
| Accent3 | #84C4D7 | 青色 |
| Highlight | #FFE483 | 金黄点缀 |

- **风格**：深蓝为主的学术严肃风，紫色系渐变辅助，金黄作为强调色
- **字体**：黑体(标题) + 等线(正文) + Arial/Times New Roman(西文)
- **字号梯度**：54→48→36→28→24→20→16→14 pt（8级）

### 配色方案 B：莫兰迪暖色（模板4）
| 角色 | 色值 | 说明 |
|------|------|------|
| Primary | #5ABB93 | 绿色 |
| Secondary | #EF5B43 | 红橙 |
| Accent1 | #F2B973 | 金色 |
| Accent2 | #756271 | 灰紫 |
| Accent3 | #858976 | 灰绿 |
| Text Dark | #543C4F | 深紫(文字) |
| BG Main | #EBEAE2 | 米色背景 |

- **风格**：莫兰迪低饱和暖色系，多色竖向色带拼接，米色背景
- **字体**：微软雅黑(全场景) + Calibri(西文)
- **字号梯度**：66→54→44→36→28→22→18→16→14→9.3 pt（10级）

### 布局体系对比
| 维度 | 参考3 | 模板4 |
|------|-------|-------|
| 总页数 | 21 | 28 |
| 封面变体 | 2 | 2 |
| 目录/过渡页 | 10 | 1 |

### 装饰手法
- **参考3**：大面积圆角矩形色块(4x6.7in) + 白色文字叠加 + 几何三角装饰 + 组合条目块
- **模板4**：全高竖向色带(1.3x7.5in)多色拼接 + 圆形/多边形装饰组合 + 底色条标题
