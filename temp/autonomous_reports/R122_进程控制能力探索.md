## 探索内容

### 1. 现有能力分析
- **Python标准库**: subprocess (启动), os.kill (终止), multiprocessing (多进程)
- **第三方库**: psutil 7.2.2 (已安装，功能强大)
- **现状**: 项目中无专门的进程管理工具

### 2. 实现成果

创建 `process_manager.py` 进程管理器，提供完整的进程生命周期管理：

**核心功能**:
```python
class ProcessManager:
    start_process(name, command, cwd, env, shell) -> Dict
    stop_process(name, timeout, force) -> Dict
    restart_process(name) -> Dict
    monitor_process(name) -> Dict
    auto_restart_daemon(name, max_restarts, check_interval) -> Dict
    list_processes() -> List[Dict]
```

### 3. 关键发现

#### 3.1 进程启停
- ✅ **优雅停止**: terminate() + wait() + kill() 三级策略
- ✅ **进程追踪**: 使用字典管理进程元数据 (pid, cmd, start_time)
- ✅ **状态检查**: psutil.pid_exists() 快速判断进程存活

#### 3.2 资源监控
- ✅ **CPU使用**: cpu_percent(interval=0.1) 实时监控
- ✅ **内存使用**: memory_info().rss 获取物理内存
- ✅ **进程状态**: status() 返回 running/sleeping/stopped 等
- ✅ **线程数**: num_threads() 监控并发情况

#### 3.3 自动重启
- ✅ **守护模式**: 阻塞式循环检查进程状态
- ✅ **重启限制**: max_restarts 防止无限重启
- ✅ **检查间隔**: 可配置 check_interval
- ⚠️ **局限**: 阻塞式设计，适合单进程守护

### 4. 最佳实践

#### 4.1 安全停止流程
```python
1. terminate() - 发送 SIGTERM，允许进程清理
2. wait(timeout) - 等待进程优雅退出
3. kill() - 超时后强制 SIGKILL
```

#### 4.2 进程监控策略
- 短间隔监控 (5-10秒) 适合关键服务
- CPU监控需要 interval 参数，避免返回 0
- 内存单位转换: rss / 1024 / 1024 = MB

#### 4.3 重启策略
- 重启前保存启动参数 (cmd, cwd, env)
- 停止后等待 0.5 秒再启动，避免端口占用
- 限制重启次数，防止崩溃循环

### 5. 能力边界

#### 5.1 已实现

### 7. 使用示例

```python
from process_manager import ProcessManager

pm = ProcessManager()

# 启动进程
pm.start_process("myapp", "python app.py", cwd="/path/to/app")

# 监控进程
status = pm.monitor_process("myapp")
print(f"CPU: {status['cpu_percent']}%, MEM: {status['memory_mb']}MB")

# 重启进程
pm.restart_process("myapp")

# 自动守护 (阻塞)
pm.auto_restart_daemon("myapp", max_restarts=5, check_interval=10)
```
