### 2. 核心功能

#### AudioTranscriber类
```python
class AudioTranscriber:
    def __init__(self, language="zh-CN")
    def transcribe(audio_path, engine="google") -> Dict
    def transcribe_long_audio(audio_path, chunk_length=30) -> List[Dict]
    def export_txt(results, output_path)
    def export_srt(results, output_path)
    def export_json(results, output_path)
```

**功能特性**:
- 单次转录：transcribe()，适合短音频（<1分钟）
- 长音频转录：transcribe_long_audio()，自动分段处理
- 多格式导出：TXT/SRT/JSON
- 时间戳支持：SRT格式包含精确时间戳

#### 便捷函数
```python
def quick_transcribe(audio_path, output_format="txt", language="zh-CN")
```

一键转录并导出，自动选择合适的转录方法。

### 3. 支持格式

**输入格式**:
- mp3: 最常用音频格式
- wav: 无损音频格式
- m4a: Apple设备常用格式
- flac: 无损压缩格式

**输出格式**:
- TXT: 纯文本，适合阅读
- SRT: 字幕格式，包含时间戳
- JSON: 结构化数据，包含完整信息

### 4. 使用示例

#### 快速使用
```python
from audio_transcription import quick_transcribe

# 一键转录
output_path = quick_transcribe("speech.mp3", output_format="txt")
print(f"转录完成: {output_path}")
```

#### 完整使用
```python
from audio_transcription import AudioTranscriber

transcriber = AudioTranscriber(language="zh-CN")

# 短音频
result = transcriber.transcribe("short.wav")
transcriber.export_txt([result], "output.txt")

# 长音频
results = transcriber.transcribe_long_audio("long.mp3", chunk_length=30)
transcriber.export_srt(results, "output.srt")
```

#### 多引擎支持
```python
# 使用Google引擎（默认）
result = transcriber.transcribe("audio.mp3", engine="google")

# 使用离线Sphinx引擎
result = transcriber.transcribe("audio.mp3", engine="sphinx")

# 使用Wit.ai引擎
result = transcriber.transcribe("audio.mp3", engine="wit")
```
