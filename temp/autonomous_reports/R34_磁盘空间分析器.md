# R34 | 磁盘空间分析器 disk_analyzer.py

## 任务
开发 `disk_analyzer.py`：扫描指定路径，生成包含 Top50大文件、目录占用饼图、重复文件检测、临时文件清理建议的 HTML 可视化报告。

## 产出物
- **`disk_analyzer.py`** (16KB, ~450行) — 完整的磁盘分析工具
- **`disk_report_project.html`** (30KB) — GenericAgent 项目扫描演示报告

## 功能清单

| 功能 | 实现方式 | 状态 |
|------|----------|------|
| 磁盘概况卡片 | 总文件数/总大小/盘符使用率 | ✅ |
| Top 50 大文件 | 全目录递归扫描+排序 | ✅ |
| 目录占用饼图 | 纯 SVG 扇形绘制(无依赖) | ✅ |
| 重复文件检测 | 文件大小预筛 + MD5 哈希比对 | ✅ |
| 临时文件清理建议 | 匹配 15+ 种模式(.tmp/.log/.cache/node_modules等) | ✅ |
| HTML 报告 | 单文件自包含，暗色主题，响应式 | ✅ |

## 技术要点
- **零外部依赖**：仅用 os/hashlib/collections/datetime 标准库
- **SVG 饼图**：手算三角函数绘制扇形 `<path>`，支持 large-arc-flag
- **GBK 兼容**：所有 print 输出使用 ASCII 字符，避免 Windows 控制台编码问题
- **CLI 接口**：`python disk_analyzer.py [路径] [-o 输出文件]`，默认扫描当前目录

## 验证结果

### 小目录测试 (autonomous_reports/)
- 扫描成功，HTML 13KB，包含全部 5 个功能区块

### 中等项目测试 (D:/GenericAgent/, 9028 文件)
- **总大小**: 367.9 MB，耗时 1.9 秒
- **重复文件**: 165 组
- **临时/缓存文件**: 1,574 个 (77.6 MB 可清理)
- **HTML 报告**: 30,350 字节，7 个 SVG 路径，114 个表格行

### 全盘扫描 (D:\ 根目录)
- 超时(>180s)，文件量过大。建议：未来可加进度条或分区扫描

## 已知限制
1. 全盘扫描耗时较长（数十万文件时 >3 分钟），适合项目级/目录级使用
2. 重复文件检测对大文件(>100MB)跳过哈希以避免卡顿
3. 饼图最多显示 10 个扇区，其余归入"其他"

## 使用示例
```bash
# 扫描当前目录
python disk_analyzer.py

# 扫描指定路径并自定义输出
python disk_analyzer.py D:/Projects -o my_report.html

# 扫描 C 盘用户目录
python disk_analyzer.py C:/Users/YourName
```
