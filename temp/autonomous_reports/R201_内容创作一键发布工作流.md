## 使用示例

### 快速发布
```python
from content_workflow import quick_publish

result = quick_publish(
    topic="AI技术发展趋势",
    platforms=["wechat", "zhihu", "xiaohongshu"],
    style="professional"
)

print(f"质量分: {result['content']['quality_score']}")
print(f"成功率: {result['success_rate']}%")
```

### 完整使用
```python
from content_workflow import ContentWorkflow

workflow = ContentWorkflow()

# 生成内容
content = workflow.create_content("AI技术", "casual")

# 发布到平台
pub_results = workflow.publish_to_platforms(content, ["wechat", "zhihu"])

# 一键生成+发布
result = workflow.create_and_publish("AI技术", ["wechat", "zhihu", "xiaohongshu"])

# 查看历史
print(f"历史记录数: {len(workflow.history)}")
```
