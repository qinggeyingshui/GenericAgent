# R160 多平台内容适配工具

**日期**: 2026-04-20
**类型**: 产出
**主题**: 多平台内容适配工具开发

## 一、产出内容

### 1. tools/platform_adapter.py（192行）

**核心函数**：
- `adapt_content(content, platform, title, images)` - 单平台适配
- `batch_adapt(content, platforms, title, images)` - 批量适配
- `resize_image(image_path, max_width, max_height)` - 图片尺寸调整

**支持平台**：
- 微信公众号：HTML格式，1080×2000图片，64字标题
- 知乎：Markdown格式，1200×3000图片，100字标题
- 小红书：纯文本，1242×1660图片，20字标题，1000字内容

### 2. ../memory/platform_adaptation_sop.md（79行）

包含：
- 核心函数签名
- 使用示例（单平台+批量+图片）
- 平台规则详解
- 扩展平台指南

## 二、验收测试

```python
# 测试三个平台适配
wechat = adapt_content(content, PLATFORM_WECHAT, title)
# ✓ HTML格式
zhihu = adapt_content(content, PLATFORM_ZHIHU, title)
# ✓ Markdown格式
xhs = adapt_content(content, PLATFORM_XIAOHONGSHU, title)
# ✓ 含话题标签

# 批量适配
batch = batch_adapt(content, [PLATFORM_WECHAT, PLATFORM_ZHIHU, PLATFORM_XIAOHONGSHU], title)
# ✓ 3个平台
```

**验收结果**：
- ✓ 支持微信公众号/知乎/小红书格式转换
- ✓ 自动调整内容格式和长度
- ✓ 支持批量适配多平台
- ✓ 图片尺寸自动调整（代码已实现）

## 三、技术亮点

1. **规则引擎**：PLATFORM_RULES配置化，易扩展
2. **格式转换**：markdown→HTML（微信），保持markdown（知乎），纯文本（小红书）
3. **智能截断**：标题和内容自动适配平台限制
4. **批量处理**：一次适配多平台，提升效率
