## 3. 实现过程

### 3.1 初始尝试与问题

首次实现中，为了强制设置中文字体，尝试对底层 `CT_TextCharacterProperties` 对象使用：

```python
rPr = run._r.get_or_add_rPr()
rPr.setdefault('w:eastAsia', DEFAULT_CN_FONT)
```

执行时报错：

```text
AttributeError: 'CT_TextCharacterProperties' object has no attribute 'setdefault'
```

原因：`CT_TextCharacterProperties` 是一个XML对象，不是字典，没有 `setdefault` 方法。该细粒度 EastAsia 字体设置对当前任务不是关键需求，因此选择简化策略。

### 3.2 最终实现方案

采用简化的样式设置函数 **仅** 操作 `run.font` 属性和段落对齐，不再触碰底层 rPr：

```python
DEFAULT_CN_FONT = "等线"

def set_text_frame_style(tf, font_size=28, bold=False, align=PP_ALIGN.LEFT):
    for p in tf.paragraphs:
        if not p.runs:
            run = p.add_run()
        else:
            run = p.runs[0]
        run.font.name = DEFAULT_CN_FONT
        run.font.size = Pt(font_size)
        run.font.bold = bold
        p.alignment = align
```

在此基础上，使用 `python-pptx` 的空白布局 `slide_layouts[5]` 构建各类页面。
