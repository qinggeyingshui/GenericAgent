- 扫描范围：
  - `./`（当前项目工作目录）
  - `../`（上层项目根目录）
- 过滤规则：
  - 文件扩展名：`.py`, `.md`, `.json`, `.yaml`, `.yml`, `.sh`, `.bat`
  - 关键词（文件路径或名称中包含之一）：  
    `paper`, `arxiv`, `scholar`, `gnn`, `research`,  
    `teaching`, `lesson`, `course`, `syllabus`,  
    `skill`, `kb`, `knowledge`, `autonomous`, `task`
  - 跳过目录：`.git`, `__pycache__`, `.venv`, `venv`, `.idea`, `.mypy_cache`, `.pytest_cache`

## 3. 枚举到的脚本与配置

按功能大类整理如下。

### 3.1 自主任务与调度相关 SOP

- `../memory/autonomous_operation_sop.md`  
  - 描述自主探索任务的规范、报告位置、history 记录格式等。
- `../memory/autonomous_operation_sop/task_planning.md`  
  - 自主任务下的任务规划细则。
- `../memory/scheduled_task_sop.md`  
  - 定时任务相关 SOP，与自主任务逻辑区分。

### 3.2 Skill 搜索与索引相关

- `../memory/skill_search/SKILL.md`  
  - 描述 skill_search 能力与 SkillIndex 结构（key、name、summary、tags、form 等）。
- `../memory/skill_search/skill_search/__init__.py`  
- `../memory/skill_search/skill_search/__main__.py`  
- `../memory/skill_search/skill_search/engine.py`  
  - 提供“技能搜索引擎”，支持基于元信息的 skill 检索。  
  - 当前仅见到“索引与搜索”功能，尚未发现统一的 skill 运行时（按 key 调用 skill 的执行层）。

### 3.3 教案与教学知识库 SOP / 规划

- `../memory/teaching_kb_sop.md`  
  - 教案知识库结构与操作规范。
- `../reflect/autonomous.py`  
  - 与自主行为相关的反思逻辑（需要时可进一步阅读以理解行为模式）。
- `autonomous_reports/R01_教案助手TODO规划.md`  
  - 教案助手相关 TODO 规划。
- `autonomous_reports/R02_程序设计课样例教案.md`  
- `autonomous_reports/R03_通用教案模板.md`  
- `autonomous_reports/R04_浏览器链路修复与GNN检索边界.md`  
- `autonomous_reports/R05_GNN论文追踪表结构设计.md`  
- `autonomous_reports/R06_教案助手知识库结构规划.md`  
  - 与教案设计、模板、知识库结构及 GNN 论文追踪相关的已有报告，可直接复用其结构与经验。

### 3.4 GNN 论文追踪与阅读模板

- `gnn_paper_tracker_schema.json`  
  - GNN 论文追踪表的 schema 定义。
- `gnn_paper_tracker_template.md`  
  - GNN 论文阅读/追踪的 markdown 模板，可直接用作后续阅读记录。

### 3.5 GNN 论文集与本地“research-paper-kb-like”实现

- `gnn_papers/PAPERS.md`  
  - 存储通过本地脚本抓取并整理的 GNN + LLM 相关论文列表。
- `local_skills/research-paper-kb/SKILL.md`  
  - 本地自定义 skill 描述，key 为 `local/research-paper-kb`，对标远程的 `research-paper-kb` 能力。
- `local_skills/research_paper_kb_like.py`  
  - 本地脚本，实现类似 `research-paper-kb` 的功能：
    - 调用 arXiv API；
    - 解析 Atom XML；
    - 将论文以结构化 markdown 形式追加到 `gnn_papers/PAPERS.md`。

> 结论：当前环境中，存在 skill 索引与搜索（skill_search），但并无统一的 “按 key 执行 skill” 的运行时。因此，为了具备“查论文→存储→汇总”的可执行链路，采用了“本地实现等价 skill + 本地 SKILL 描述”的方案。

### 3.6 教案知识库现有样例

- `plan_teaching_kb/plan.md`  
  - 教案知识库规划的计划文件。
- `teaching_kb/courses/编译原理/lessons/L02_词法分析/lesson_plan.md`  
  - “编译原理 - 词法分析”课次的样例教案。
- `teaching_kb/courses/编译原理/lessons/L02_词法分析/materials_index.md`  
  - 对应课次的教学材料索引。
