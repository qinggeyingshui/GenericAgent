## 1. 背景与目标

### 1.1 背景

依据 R06《教案助手知识库结构规划》与示例课次：

- 知识库根目录：`./teaching_kb/`
- 课程示例：`./teaching_kb/courses/编译原理/lessons/L02_词法分析/`
- 教案主体文件：`lesson_plan.md`

示例教案包含典型字段：

- 基本信息：课程名、课次编码、主题、学时等
- 教学目标
- 教学内容概述（按知识点列出）
- 教学重难点
- 教学过程：
  - 导入
  - 新课讲解
  - 课堂练习
  - 课堂小结
- 板书设计
- 作业布置

用户的 PPT 偏好（来自既往对话）：

- 学术感为主，但不过于死板
- 有插图（流程图、结构示意、例子等），避免纯文字
- 主要使用场景：会议/答辩大屏（A 场景），字体大、对比度高、结构清晰

### 1.2 本任务目标

本任务 R16 旨在：

1. 设计一套从「教案 lesson_plan.md」到「授课 PPT 结构」的映射规则；
2. 明确：
   - 输入：教案中的字段/章节
   - 输出：PPT 的页级结构（各页类型与内容槽位）
   - 中间：字段 → 页类型 & 内容填充方式的映射表
3. 给出至少 1 页「教案内容 → PPT 页」的详细示例；
4. 默认适配用户偏好的 PPT 风格（学术感 + 插图 + 会议/大屏）。

本文件只做构想草案，不直接生成 PPT 文件；后续可与已有 PPT 模板（如 `academic_chinese_template_v1.pptx`）结合实现半自动生成。


## 2. 教案结构简要回顾（以 L02 为例）

以 `编译原理 - L02 词法分析` 的 `lesson_plan.md` 为代表，教案典型结构如下（抽象层面）：

1. **基本信息**
   - 课程名称
   - 课次编码（如 L02）
   - 课次主题（如「词法分析」）
   - 授课教师
   - 学时数 / 授课时间

2. **教学目标**
   - 若干条学习目标，例如：
     - 理解词法分析在编译过程中的位置和作用
     - 掌握词法分析的输入输出形式
     - 理解正则表达式在词法分析中的作用
     - …

3. **教学内容概述**
   - 按知识点列出教学内容，例如：
     - 编译过程总览与词法分析位置
     - 词法分析的任务与输入输出
     - 正则表达式与词法规则
     - 有限自动机及其与正则表达式的关系
     - …

4. **教学重难点**
   - 教学重点：如“理解词法分析在编译过程中的作用及输入输出形式”
   - 教学难点：如“从正则表达式到有限自动机的转换思想”

5. **教学过程**
   - 导入（例子、问题、引子）
   - 新课讲解（按内容概述中的知识点展开，配说明/例子/图示）
   - 课堂练习（习题或代码片段）
   - 课堂小结（对本课内容归纳）

6. **板书设计**
   - 板书结构或关键板书内容要点（通常是简明的要点/图示安排）

7. **作业布置**
   - 课后作业题目或学习任务
   - 可能引用 `exercises/` 或 `materials/` 之类的资源文件


## 3. 教案字段 → PPT 结构映射规则（骨架）

### 3.1 单课次 PPT 的推荐页级结构

针对单次课（例如 L02 词法分析），建议生成的 PPT 页级骨架为：

1. 封面页（Cover）
2. 本课目标页（Objectives）
3. 内容大纲页（Outline）
4. 重难点提示页（Key Points / Difficulties）
5. 导入页（Introduction / Motivation）
6. 知识点讲解页（若干页，按内容概述拆分）
7. 课堂练习页（Exercises）
8. 本课小结页（Summary）
9. 作业 & 拓展阅读页（Homework & Further Reading）

说明：

- 上述 9 个大类中，第 6 类“知识点讲解页”包含多页，这是主要篇幅。
- 如果某些教案字段为空，可选择跳过相关页型。
- 所有页面默认使用学术风版式：标题明显、正文分要点、侧边或下方留插图位，适配大屏展示。

### 3.2 字段到 PPT 部分的总体映射表

下表给出教案字段到 PPT 页/部分的映射：

| 教案字段/内容                      | PPT 部分/页型                       | 内容映射方式                                                         |
|------------------------------------|--------------------------------------|----------------------------------------------------------------------|
| 基本信息：课程名、课次编码、主题  | 封面页                               | 标题=课次主题；副标题=课程名+课次编码；页脚可放授课教师、时间       |
| 基本信息：课程名、课次编码        | 页脚全局信息                         | 可选：在后续所有页面页脚显示“课程名 Lxx”                            |
| 教学目标（多条）                  | 本课目标页                           | 标题=“本课学习目标”；正文为项目符号列表                             |
| 教学内容概述（知识点列表）        | 内容大纲页                           | 标题=“内容大纲”；正文为知识点标题形成的目录式列表                   |
| 教学重难点：重点+难点            | 重难点提示页                         | 标题=“教学重点与难点”；中间区列出“重点”“难点”两块内容              |
| 教学过程-导入                     | 导入页                               | 标题=“导入 / 引入问题”；左侧列出导入情境/问题；右侧配相关示意图     |
| 教学内容概述 + 新课讲解细节      | 知识点讲解页（每个知识点1–2页）      | 每个知识点生成单独小节标题页和1+内容页，详情见 3.3                  |
| 教学过程-课堂练习                | 课堂练习页（1–2页）                  | 标题=“课堂练习”；逐题列出题干；可预留“思考提示”文本区              |
| 教学过程-课堂小结                | 本课小结页                           | 标题=“本课小结”；用 3–5 条 bullet 总结关键知识                     |
| 板书设计                          | 可选板书结构页或融入小结页          | 标题=“板书设计回顾”或在小结页右侧放板书结构示意                      |
| 作业布置                          | 作业 & 拓展阅读页                    | 标题=“课后作业与阅读”；列出作业条目；可附参考材料/章节             |
| 其他相关文件（exercises/materials）| 附录/参考资料页（可选）             | 标题=“附录/参考资料”；列出文件名或链接                             |


### 3.3 知识点讲解页的细化规则

知识点讲解是 PPT 的主体，规则如下：

1. 来源字段：
   - 教学内容概述中的每一条“知识点标题”；
   - 教学过程-新课讲解中的对应段落（若存在更详细描述）。

2. 每个知识点生成的基本页型：

   - **知识点起始页（Section Intro）**（可选，但推荐用在较大的知识点上）  
     - 标题：知识点名称（例如「词法分析的任务与输入输出」）  
     - 副标题（可选）：所在章节或小节标号（例如“2.2”）  
     - 正文：1–3 条关于该知识点的目标或核心问题（可由教案中对该知识点的简要说明提炼）  
     - 插图占位：右侧或底部，提示放该知识点相关的结构图/流程图。

   - **知识点内容页（1–2 页）**
     - 页 1：概念与框架
       - 标题：同知识点名称或略作缩写
       - 正文：列出定义、输入/输出、在整体中的位置等  
       - 插图：右侧或底部放概览流程图/结构图
     - 页 2（如有需要）：例子或推导
       - 标题：该知识点下的“例子”或“示例推导”
       - 正文：具体例子、推导步骤要点
       - 插图：代码片段截图、表格或更细的局部结构图

3. 风格约束：

- 标题字号明显，适配大屏；
- 单页最多 5–7 个 bullet，避免密集文字墙；
- 每个重要知识点至少有 1 个图示建议占位（逻辑图、层次结构、示例流程、代码片段截图等）；
- 若已有对应素材文件（如 `materials` 或 `slides` 目录中），可在自动生成阶段尝试匹配文件名关键字，将其作为插图来源。


## 4. 单页映射示例（以「词法分析的任务与输入输出」为例）

下面用一个具体示例展示从教案到 PPT 页的映射。

### 4.1 假定教案中的相关原文

假设在 `lesson_plan.md` 中有如下内容（示意）：

- 教学内容概述中的一条：
  - 「词法分析的任务与输入输出」

- 教学过程-新课讲解中的相应段落（伪示例）：

  > 词法分析器的主要任务是将源程序的字符流转换为记号（Token）序列，为后续的语法分析提供输入。  
  > 输入：源程序的字符序列。  
  > 输出：记号（Token）序列，每个记号包含种类和属性值。  
  > 在编译过程中，词法分析位于源程序和语法分析之间。

### 4.2 对应 PPT 页设计（示例页）

**页类型**：知识点内容页 – 概念与框架

**页面元素设计：**

- 标题区：
  - 文本：`词法分析的任务与输入输出`

- 正文要点区（左侧）：
  - 一级 bullet：
    1. 任务：
       - 将**源程序字符流**转换为**记号（Token）序列**
       - 为语法分析等后续阶段提供结构化输入
    2. 输入：
       - 源程序的**字符序列**
    3. 输出：
       - 记号（Token）序列
       - 每个记号包含：**种类（token type）** 与 **属性值（attribute value）**
    4. 在编译流程中的位置：
       - 位于**源程序**和**语法分析**之间

- 插图建议区（右侧）：
  - 建议图示标题：`编译前端中的词法分析位置`
  - 图示结构（从左到右）：
    - 方块：“源程序（字符流）”
    - 箭头指向：“词法分析器”
    - 再箭头指向：“记号（Token）序列”
    - 再箭头指向：“语法分析器”
  - 图示风格：简洁模块图，高对比度颜色（例如深色框+浅色背景），适合大屏展示。

- 页脚（全局约定，可选）：
  - 左侧：`编译原理 - L02 词法分析`
  - 右侧：页码（例如 `5 / 32`）

### 4.3 文字 → PPT 结构的形式化映射描述

**输入片段（教案字段）：**

- 字段：教学内容概述 → 知识点标题 = `词法分析的任务与输入输出`
- 字段：教学过程-新课讲解 → 段落文本（任务 / 输入 / 输出 / 位置）

**映射规则触发：**

1. 知识点标题 → PPT 页标题。
2. 段落中显式以“任务 / 输入 / 输出 / 位置”组织的语句 → 拆分为 3–4 个 bullet 组，分别对应“任务/输入/输出/位置”主题。
3. “位于……之间”等位置描述 → 单独作为“在编译流程中的位置”子 bullet。
4. 上下文关键词（“源程序”“词法分析”“Token”“语法分析”） → 提示生成模块流程图的节点和连线。

**输出片段（PPT 结构描述）：**

- slide_type: `"concept_with_flow_diagram"`
- title: `"词法分析的任务与输入输出"`
- bullets:
  - `"任务：将源程序字符流转换为记号（Token）序列，为后续语法分析提供输入"`
  - `"输入：源程序的字符序列"`
  - `"输出：记号（Token）序列，每个记号包含种类和属性值"`
  - `"在编译流程中的位置：位于源程序和语法分析之间"`
- diagram_hint:
  - nodes: `["源程序（字符流）", "词法分析器", "Token 序列", "语法分析器"]`
  - edges: `[("源程序（字符流）", "词法分析器"), ("词法分析器", "Token 序列"), ("Token 序列", "语法分析器")]`
  - layout: `"horizontal_pipeline"`

这种结构化描述可进一步与具体 PPT 模板字段（如 python-pptx 的布局槽位）对接，实现程序化生成。


## 5. 自动生成流程设想（简要）

在未来自动化实现中，可以按如下流程将教案转为 PPT：

1. **解析阶段**
   - 解析 `lesson_plan.md`：
     - 提取基本信息（课程名、课次编码、主题、教师等）
     - 提取教学目标列表
     - 提取教学内容概述（知识点标题列表）
     - 提取教学重难点文本
     - 提取教学过程各小节（导入/新课讲解/练习/小结）
     - 提取板书设计、作业布置

2. **结构规划阶段**
   - 按 3.1 的骨架生成“预期页列表”（带页型标记）：
     - cover, objectives, outline, key_points, intro, topic_section_1..n, exercises, summary, homework
   - 对于每个 topic_section：
     - 查找教学过程-新课讲解中与其标题最匹配的段落，作为该知识点的核心内容来源。

3. **内容填充阶段**
   - 根据映射规则：
     - 把文本切分为 bullet 要点；
     - 为导入/新课/小结/练习页生成相应 bullet/题目；
     - 为每个知识点生成概念页和（可选）例子页；
     - 为重难点生成重点/难点两栏内容。

4. **插图/示意图建议阶段**
   - 基于关键词决定插图类型：
     - 含“输入/输出/流程/阶段/之间”等 → 推荐流程图
     - 含“层次/组成部分/模块”等 → 推荐结构图或分层框图
     - 含“例子/示例/代码”等 → 推荐代码片段截图或示例文本框
   - 若 `materials/` 中已有匹配文件名的 PNG/PDF 等，可作为插图来源绑定至对应页。

5. **模板填充阶段**
   - 与某个具体模板（如 `academic_chinese_template_v1.pptx`）对接，将：
     - 页型 → 模板中的版式（layout）
     - 标题/正文/图示建议 → 填入对应文本框和图片占位符
   - 输出：`L02_词法分析.pptx`，可供人工微调。

## 6. 后续可扩展点（草案）

1. **多课次合并**
   - 支持生成“期中/期末复习”类 PPT，从多个 lesson_plan 中抽取小结和重难点汇总。
2. **难度标注 & 时间分配**
   - 从教案中标注每一部分占用时间，生成 PPT 时在页脚或隐藏注释中标记“建议讲解时长”。
3. **与作业/练习库联动**
   - 自动从 `exercises` 目录选取对应标签的习题生成课堂练习页和课后作业页。
4. **语种和风格切换**
   - 横向扩展到英文授课版本；同一教案生成中英双语 PPT。
5. **与教案编辑器集成**
   - 在教案编辑界面中预览“预计生成的 PPT 大纲”，实现双向联动（改教案→PPT 结构更新）。
