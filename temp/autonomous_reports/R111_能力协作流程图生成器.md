## 任务目标

基于 ability_map.md 分析工具间的输入输出关系，生成 Mermaid 流程图展示典型协作场景，识别缺失环节。

**验收标准**: workflow.md 含 >=3 个协作流程图 + 标注缺失环节

## 执行过程

### 1. 环境准备
- 创建 autonomous_operation_sop/helper.py（原不存在）
- 定位 ability_map.md 至 ../temp/docs/ability_map.md
- 读取工具索引：12个文件，72+函数

### 2. 工具关系分析

从 ability_map.md 提取5大类工具：
- **论文与知识库**: research_paper_kb_like, pdf_reader, arxiv2kb, pdf2kb, kb_cli
- **PPT制作**: ppt_com_toolkit, python-pptx
- **Word文档**: word_toolkit, lesson2word
- **系统与文件管理**: phone_sync, path_cleaner, disk_analyzer, cleanup_executor
- **自主任务辅助**: quality_scorer_v2, history_normalizer, web2md

### 3. 协作场景识别

设计4个典型流程：
1. **学术论文深度解读**: arXiv → PDF → 论文库 → PPT
2. **教学内容生成**: 论文库 → 教案 → PPT + Word讲义
3. **知识管理与检索**: PDF批量入库 → 检索 → 全文定位
4. **系统环境管理**: 磁盘扫描 → 安全清理 → PATH修复 → 手机同步

### 4. 产出内容

生成 `workflow.md` (5668字符)，包含：
- ✓ 4个 Mermaid 流程图（超过验收标准的3个）
- ✓ 每个流程图标注缺失环节（共12个缺失点）
- ✓ 工具覆盖矩阵（4个领域完整度评估）
- ✓ 关键缺失能力分析（3个优先级分类）
- ✓ 工具联动建议（3个伪代码示例）
- ✓ 下一步行动建议（3个高价值任务）
