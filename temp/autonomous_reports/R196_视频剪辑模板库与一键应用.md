## 实现方案

### 1. 技术架构
- 基于moviepy延迟导入（避免依赖问题）
- 模块化设计：管理器+应用器
- JSON格式模板存储

### 2. 核心模块

#### VideoTemplateManager
模板管理器，负责模板的CRUD操作：
- save_template(): 保存模板到JSON
- load_template(): 从JSON加载模板
- list_templates(): 列出所有模板
- delete_template(): 删除模板

#### VideoTemplate
模板应用器，提供预设模板和应用功能：
- opening_template(): 开场模板（标题+淡入）
- ending_template(): 片尾模板（文字+淡出）
- apply_template(): 一键应用完整模板

### 3. 预设模板

#### 标准开场模板
```python
opening = create_standard_opening("标题", 3.0)
# 包含：标题文字、持续时间、淡入淡出效果
```

#### 标准片尾模板
```python
ending = create_standard_ending("感谢文字", 3.0)
# 包含：结束文字、持续时间、淡入淡出效果
```

### 4. 模板结构

```json
{
  "opening": {
    "type": "opening",
    "title": "标题文字",
    "duration": 3.0,
    "fade_in": 0.5,
    "fade_out": 0.5
  },
  "ending": {
    "type": "ending",
    "text": "结束文字",
    "duration": 3.0,
    "fade_in": 0.5,
    "fade_out": 0.5
  }
}
```

## 使用示例

### 基础使用

```python
import sys
sys.path.append('./tools')
import video_templates

# 1. 创建模板管理器
mgr = video_templates.VideoTemplateManager()

# 2. 创建模板
template = {
    "opening": video_templates.create_standard_opening("欢迎", 3.0),
    "ending": video_templates.create_standard_ending("谢谢", 3.0)
}

# 3. 保存模板
mgr.save_template("my_template", template)

# 4. 应用模板（需要moviepy）
```
