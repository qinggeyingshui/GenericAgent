## 正确的使用流程

### 方式一：使用 complete_task() (推荐)
```python
from autonomous_operation_sop.helper import complete_task

# 在报告末尾添加元数据标签
report_content = '''
# R127 任务报告

...任务内容...

---
[skill_used] knowledge_management.paper_acquisition
[gaps_found] system_management.process_control.进程优先级调整
[gaps_solved] mobile_control.file_sync.增量同步
[ability_upgraded] mobile_control.file_sync -> intermediate
'''

# 保存报告
with open('./temp_report.md', 'w', encoding='utf-8') as f:
    f.write(report_content)

# 一键完成收尾（自动更新技能树）
result = complete_task(
    taskname="任务简短描述",
    historyline="探索 | 任务简短描述 | 关键成果",
    report_path="./temp_report.md"
)
print(result)
```

## 元数据标签规范

### 必需格式
```
---
[skill_used] category.skill | category.skill
[gaps_found] category.skill.具体缺口描述
[gaps_solved] category.skill.具体缺口描述
[ability_upgraded] category -> level
```

### 示例
```
---
[skill_used] knowledge_management.paper_acquisition | document_generation.ppt_creation
[gaps_found] media_processing.image_processing.OCR文字识别 | system_management.process_control.进程优先级调整
[gaps_solved] document_generation.word_editing.中文列表样式兼容
[ability_upgraded] document_generation -> advanced
```

### 注意事项
1. **必须有 `---` 分隔符**，否则 auto_skill_update_lite.py 会跳过
2. 多个值用 `|` 分隔
3. gaps 格式：`category.skill.具体描述`
4. ability_upgraded 格式：`category -> level`
