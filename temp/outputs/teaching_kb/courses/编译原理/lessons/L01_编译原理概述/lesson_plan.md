# 编译原理 - L01 编译原理概述 教案

## 基本信息
- 课程名称：编译原理
- 课次编码：L01
- 主题：编译原理概述
- 教学目标：
  - 理解编译器在软件开发中的核心地位与作用
  - 掌握编译过程的基本阶段划分（词法、语法、语义、中间代码、优化、目标代码）
  - 了解解释器与编译器的区别与联系
  - 建立对本课程学习路线的整体认知
- 建议学时：2 学时

## 教学内容概述
- 什么是编译器：从源程序到目标程序的翻译
- 编译器的历史与发展
- 编译过程的六个阶段概览
- 编译器与解释器的对比
- 编译器在现代软件工程中的应用（JIT、LLVM、语言设计）

## 教学重难点
- 重点：编译过程六个阶段的功能与相互关系
- 难点：理解前端与后端的划分及各阶段的输入输出

## 教学过程
### 1. 导入
- 提问：我们每天写的代码是如何变成可执行程序的？
- 展示一段 C 语言代码从源文件到可执行文件的完整流程。

### 2. 新课讲解
- 编译器的定义与分类（单遍/多遍、交叉编译器等）
- 编译的六个阶段：词法分析→语法分析→语义分析→中间代码生成→代码优化→目标代码生成
- 符号表管理与错误处理贯穿全过程
- 前端（源语言相关）与后端（目标机器相关）的划分
- 解释器 vs 编译器：执行方式、性能、适用场景对比

### 3. 课堂练习
- 给定一个简单赋值语句 `a = b + c * 2`，尝试描述其经过各编译阶段的变化。
- 讨论：Python 是编译型还是解释型语言？为什么？

### 4. 课堂小结
- 回顾编译器的六个阶段及其核心功能。
- 预告下节课内容：词法分析的详细原理。
